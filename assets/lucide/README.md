# Lucide icons

Official source SVGs from [Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons), vendored with their ISC license. Feather-derived portions retain the attribution stated in LICENSE.

The supplementary `FEATHER-LICENSE` preserves Feather's full MIT notice. Keep both notices when redistributing these assets or their generated paths.

`scripts/generate-icons.ps1` converts these SVG elements into the embedded native-rendering data in `src/lucide_data.inc`. Their paths are rendered by Direct2D with round line caps and joins. No icon font, bitmap atlas, web renderer, or runtime download is used.
